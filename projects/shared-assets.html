Shared Assets.

Asset management for jointly owned property: income, expenses and receipts in one place, with a live balance for every co-owner.

What it does

When several people own something together, one of them usually does the bookkeeping and everyone else wants to see where the money goes. Shared Assets lets the administrator record each movement from their phone — with a photo or PDF of the receipt — while the other co-owners get a read-only view of the transactions and the balance.

How AI is used

Co-owners can ask the books a question in plain language — “how much did we spend on the office this year?”, “compare repairs and taxes”.

The design rule is the AI interprets, the code calculates. The model never sees the full table and never adds up numbers itself: through function calling it turns the question into query parameters, the backend filters the data and computes the exact figures, and the model writes the answer. Comparisons run as several rounds of tool calls. The result: natural answers without hallucinated numbers.

How it is built

  • No database of its own: every movement is a row in a shared Google Sheet, and receipts live in a Google Drive folder.
  • Spring Boot backend with Google Sheets and Drive APIs; OpenAI for the assistant.
  • React frontend, mobile-first, with separate roles for the administrator and the co-owners.

Stack
