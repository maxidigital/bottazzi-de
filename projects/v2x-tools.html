V2X Tools · ASN1Click.

A platform for ASN.1 and V2X (connected-vehicle) messages: convert them in the browser, manage the modules behind them, and make both available to AI assistants.

v2x.tools → asn1click.com →

V2X

What it does

V2X messages — the ones vehicles and road infrastructure exchange — are defined in ASN.1, a dense specification language. V2X Tools gives engineers a public converter to encode, decode, generate and convert these messages, and ASN1Click adds a repository where users and organisations upload, browse and validate their own ASN.1 modules.

How AI is used

The repository digests every module into a structured element index: about 1,450 elements across 26 modules, each with its type, named values, constraints, fields and annotations, stored as queryable JSONB in PostgreSQL.

This index is the knowledge base for an MCP server, so assistants such as Claude can search message types, explain what a field means and work with real data. Public and internal views are separated, and the AI can write its own enrichment annotations back into the index.

How it is built

  • Frontend — the public converter (v2x.tools) and the account app (app.asn1click.com), both React + TypeScript single-page apps behind Caddy.
  • Hub — the public entry point: resolves references, loads and converts through the engine, and owns caching.
  • Engine — the codec engine: loads a digested module tree (content-addressed) and runs convert / generate.
  • Repo — the ASN.1 authority: stores modules, parses them into trees, serves the element index and validates.
  • Users — the identity provider: Google sign-in, RS256 JWTs with JWKS, organisations, invite codes and central single sign-on.
