Freediving Courses.

Course operations for a freediving school in Mallorca, run from a Telegram bot.

≈

What it does

A freediving school runs many small courses, each with its own students, dates, places and paperwork. This bot turns the school’s Google Calendar into an operations tool: it lists upcoming courses and their students, collects the final details of each course day, sends course information and reminders to students by e-mail, and pings the instructors every evening about anything that still needs attention.

How it is built

  • Java service with the Telegram Bot API as the interface.
  • Google Calendar as the source of truth for courses; Google Sheets and Contacts for students and new enquiries.
  • Transactional e-mail through Mailjet, with delivery events fed back into the bot.
  • Scheduled jobs for daily reminders and second-day follow-ups.

Stack

Java · Telegram Bot API · Google Calendar, Sheets & Contacts APIs · Mailjet · Docker
