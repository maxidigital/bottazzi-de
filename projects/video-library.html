Video Library.

A video library and e-learning platform for training material, designed for the phone and easy to share.

ilm-media.bottazzi.de →

▶

What it does

Training courses often leave their material scattered across dozens of YouTube playlists. Video Library organises it as courses → modules → lessons → videos, so anyone can find and rewatch a specific session from their phone — and share it with people who never took the course.

How AI is used

Importing a module starts from a raw YouTube playlist. An LLM receives the video titles and returns a structured module as JSON: it groups the videos into lessons using dates, numbering and parts found in the titles, keeps the right order, and cleans each title without inventing content.

To keep the course consistent, the prompt includes an existing module as a style example. The result is shown as a proposal to review before saving, and if the AI is unavailable the import still works, just unsorted.

How it is built

  • Spring Boot backend with the YouTube Data API for playlists and the OpenAI API for sorting.
  • React frontend, mobile-first, with resizable panels on desktop.
  • Roles for administrators and viewers; e-mail notifications.

Stack

React · Spring Boot · Java 17 · YouTube Data API · OpenAI · Docker · Railway
