Audio Console.

Multi-track audio playback for live performances, from building the set to running the show.

♫

What it does

Live performances need sound cues that start, overlap and fade on time. Audio Console covers the whole workflow in the browser: upload an audio library, arrange tracks on a timeline with cues and fade-ins/outs, try them on a live mixer with up to four channels, and run the performance from a player built for the stage, with cue navigation and per-track mute.

How it is built

  • Spring Boot backend with JPA for libraries, sets, tracks and cues, and FFmpeg for audio processing.
  • React frontend with four views: library, mixer, timeline editor and performance player.
  • Packaged as a single Docker image: the frontend is embedded in the Spring Boot JAR.

Stack

React · Vite · Spring Boot 3 · Java 17 · JPA · FFmpeg · Docker · Railway
