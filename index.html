  • V2X

    EngineeringAI Main project

    V2X Tools · ASN1Click

    A platform for ASN.1 and V2X (connected-vehicle) messages, the web version of my V2X Framework and built on its codec. A public converter encodes, decodes, generates and converts messages; behind it, a module repository with accounts, organisations and single sign-on, split into independent services.   • RSU

    Engineering German Aerospace Center (DLR)

    V2X Framework

    A Java framework for sending and receiving connected-vehicle messages (CAM, DENM, CPM, MAPEM/SPATEM…) over roadside units and on-board units. It hides the radio hardware behind one API, so research applications in Java or ROS exchange messages as XML, JSON or binary with Cohda and other vendors' units. A code generator turns message definitions into Java libraries, ROS packages and Protobuf.

    Java · Maven · ASN.1 / UPER · ROS 1 & 2 · C++ · Protobuf · Kafka · GitLab CI
